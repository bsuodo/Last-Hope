# einde sprint 1 - Last Hope

Leerdoel is niet helemaal behaalt, het systeem het ik wel gemaakt,
maar er ontbreekt veel dingen waardoor je niet veel met de rendering
systeem bezig kan gaan. Er zijn ook weinig checks voor error omdat ik
zo snel mogelijk resultaten wil hebben. Maar dat geldt niet alleen voor
de rendering systeem, het geldt ook voor het systeem dat resource laadt.

Het laadt de textures maar het zegt niet wat de breedte en hoogte moet zijn.
Ondersteunt voolopig geen animaties, en is erg beperkt. Ik moet bezig met de
resource laden systeem want anders kan ik gewoon niet verder bij het renderer.

Hoewel ik niet helemaal klaar is, ben ik alsnog tevreden ik heb paar nieuwe
syntax of keywords geleerd, niet alleen daardoor, maar ook omdat ik begrijp
wat ik aan het doen ben. Tot nu toe nis het niet persee moeilijk maar
kost het gewoon tijd.

Ik ga tot nu toe de goede kant op, en wil hier meteen verder mee gaan.

Ik heb met AI proberen te werken maar het leidde me alleen maar af, ik heb
zelfs een aparte branch waarin AI code is gebruikt, het
zorgde ook dat ik niet zelf denk, wat ervoor zorgt dat niet naar me eigen
code kijk. Dus moet ik helemaal lezen wat AI deed. Meestal werkt het,
maar voor lange termijn is dit niet slim.

AI blijkt niet echt te helpen dus begon gewoon opnieuw in master branch.

Ik gebruikte chatgpt bij beide branches voor simpele vragen of syntax fouten,
bij AI branch gebruikte ik copilot extension en built in AI features.
Toen bij gebruik van vscode built in agent, stond op dat ik GPT-6 Luna gebruikte.

Mijn werkprocess was heel simpel, gewoon coderen. Gebruikte geen trello, omdat het
simpelweg gewoon geen effect had, maar vooral omdat het project nog klein is.
