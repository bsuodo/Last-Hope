# Last Hope

Dit wordt een game die ik maak voor de lol, het lijkt me leuk om dat spel uit eindelijk
met mijn vrienden of familie te spelen. Ik zou dit natuurlijk willen uitbreiden naar een
echte game als dat lukt. Maar ik vetrouw daar niet op.

Hiermee wil ik geen AI code snippets plakken, ik wil het coderen en in mijn eigen woorden
oftewel code willen implementeren.

Dit wordt een survival spel waarbij het bedoeld is om multiplayer te spelen van 1 - 4. Het
speelt zich af in 2030 op aarde die op problemen is. Omdat aarde niet meer te leven is door
de radio actieve stralingen erg warme temperatuur dus jij als astronout bent de laatste mens
op aarde en gaat op die spaceship en moet zo lang mogelijk overleven. Je kune naar andere planeet
reizen om materialen te verzamelen zoals eten drinken brandstof. Maar je moet ook opletten
voor aliens die je proberen te vermoorden. Je moet ook ervoor zorgen dat je zuurstof niet
opraakt. Het is dus een survival game en je moet zolang mogelijk overleven in de ruimte.
elke dag is half uur of een uur. het is een Procedural generated game zoals minecraft.

Maar er is een twist. Ik zal het tecniek sprite stacking gebruiken het zijn afbeelding
opgestapeld zodat het een effect geeft alsof het 3d is. Dit zorgt ervoor dat ik creatiever
kan denken.

Ik wil matrixes leren dus hoe je die illusie kan geven en ook nog is de camera kan draaien.

Alle assets zijn door mij gemaakt.

Mijn werk process is als volgt:
  1. Bij elke sprint begin ik met een plan dat staat ook op trello.
  2. Daarna begin ik meteen met programmeren, ontwerp is meestal niet nodig.
  3. Vervolgens test ik hem zelf. Pas als ik echt de basis heb, laat ik andere mijn spel testen.
